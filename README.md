# Pinball Ultra

A vertical pinball table built in [Godot 4](https://godotengine.org/) — every
visual and every sound is generated by code at runtime, no image or audio
asset files at all.

Casino-themed table: a real European roulette wheel in the center hole, a
slot machine in the top tunnel, drop targets, ramps, bumpers, multiball, a
local high-score table and an attract mode.

## Play

Download from the [Snap Store](https://snapcraft.io/pinball-ultra):

```
sudo snap install pinball-ultra
```

Or run from source (requires the [Godot 4.7 Mono](https://godotengine.org/download) editor/runtime):

```
godot4 --path . scenes/Main.tscn
```

## Controls

| Action        | Keyboard (default) | Gamepad          |
|---------------|---------------------|------------------|
| Left flipper  | Z                   | Left shoulder    |
| Right flipper | M                   | Right shoulder   |
| Launch ball   | Space               | A / Cross        |
| Nudge table   | Shift               | B / Circle       |
| Settings menu | Esc                 | Start            |

Keyboard bindings are remappable from the settings menu (Esc). Volume and
language are also set there.

## Languages

Español, English, Català — switch anytime from the settings menu.

## Project structure

Everything lives under `scripts/`: `Main.gd` drives the table and rules,
each table element (bumper, flipper, ramp, roulette, slot machine...) is
its own script/scene, `Sfx.gd` synthesizes all audio procedurally, and
`Lang.gd` holds the ES/EN/CA string table.
